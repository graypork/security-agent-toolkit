## 2교시 · IP 주소 · 사설과 공인

### 문제 2-1 · 내 IP 를 2진수로

- (가) 두 번째 파일(`warmup_2_1b.py`, 내 IPv4 주소)의 출력 네 줄:
192 11000000
168 10101000
100 01100100
163 10100011
- (나-1) `format(number, "08b")` 가 마디 하나의 10진수를 어떤 형태의 글자로 바꾸는지, 내 출력 한 줄을 예로 들어 설명하세요.
  - 답: 10진수를 8자리의 2진수로 변경, 숫자의 앞자리는 0으로 채움
- (나-2) `"08b"` 에서 `08` 을 빼고 `"b"` 만 쓰면 `10` 은 어떻게 출력되나요?
  - 답: 2진수로 출력
- (나-3) 마디마다 8자리로 맞춰 써야 하는 이유를 설명하세요.
  - 답: IPv4는 8비트짜리 숫자 4개로 주소를 표현하도록 설계됐기 때문
- (다-1) IPv4 주소가 32비트라는 것과 마디 하나가 `0` ~ `255` 사이의 값만 가진다는 것은 어떻게 이어지나요? 마디 수와 비트 수를 근거로 설명하세요.
  - 답: 한마디에 8개의 비트가 들어간다는 말은, 2진수로 이루어진 8자리의 수라는 뜻으로, 이를 10진수로 변경하면 0~255의 값만 갖게됨
- (다-2) 32비트로 만들 수 있는 주소의 개수:4,294,967,296

- (다-3) 그 개수가 나오는 계산 과정을, 비트 한 자리에 들어갈 수 있는 값의 가짓수와 자리 수를 넣어 단계별로 설명하세요.
  - 답: 한자리에 들어갈 수 있는 숫자는 0,1 두가지로. 한 마디에 2^8의 숫자를 갖을 수 있다. 따라서 2^32 = 4,294,967,296
- (다-4) 이 수의 한계가 사설 IP 와 NAT 를 쓰게 된 것과 어떻게 이어지는지 설명하세요.
  - 답: IPv4는 약 43억 개의 주소만 만들 수 있어서, 인터넷 기기가 늘어나자 공인 IP가 부족해졌고, 이를 해결하기 위해 내부 네트워크에서는 여러 기기가 사설 IP를 사용하고, 인터넷에 접속할 때는 NAT가 여러 사설 IP를 하나의 공인 IP로 변환해 공유하도록 만들었습니다. 이렇게 해서 부족한 공인 IPv4 주소를 절약할 수 있습니다.

  - 답:정적 NAT는 사설 IP와 공인 IP를 1:1로 고정 연결, 동적 NAT는 필요할 때 사용 가능한 공인 IP를 임시 할당

  - 답: 여러 PC가 공인 IP를 효율적으로 공유할 수 있어 동적 NAT를 사용. 특정 PC를 찾으려면 접속 시간과 NAT 변환 로그를 함께 확인
- (다-4) 인터넷에서 회사 내부망의 웹 서버에 접속하게 하려면 정적 NAT 과 동적 NAT 가운데 어느 방식이 맞는지 이유와 함께 설명하세요.
  - 답: 정적 NAT가 적합합니다. 외부에서 항상 같은 공인 IP로 내부 웹 서버에 접근되어야함
